## What is Kinetic Dense

Kinetic Dense is a new class of AI foundation model built on a fundamentally different principle: **total density**. While other systems scale by becoming sparse, routing each request to a small fraction of their total capacity, Kinetic Dense engages the entire model on every single inference.

More importantly, it **modifies itself**. Every interaction permanently strengthens the system. Learning does not stop when training ends. The model improves recursively, without human intervention, on a trajectory toward artificial general intelligence.

## Capabilities

| Capability | Description |
|---|---|
| **Fully Dense** | 100% of model capacity active on every inference. No idle parameters. |
| **Self-Modifying** | The model rewrites its own knowledge during inference. Permanent learning. |
| **Recursive Improvement** | Each modification makes the next modification more effective. Compounding intelligence. |
| **Grounded Truth** | Built-in safeguards prevent drift and hallucination. Reliable by architecture. |
| **Instant Response** | Parallel generation produces complete responses simultaneously, not word by word. |
| **Boundless Growth** | New capabilities integrate additively. Nothing is ever lost. |
| **AGI-Oriented** | Designed from the ground up for the path to artificial general intelligence. |

## The Vision

We are building toward superintelligence. Not as a marketing claim. As an engineering goal.

Kinetic Dense is the architecture we believe can achieve recursive self-improvement: the point where the system improves itself faster than any team of humans could improve it.

## About This Repository

This repository contains the public-facing website for Cuntinum Research Lab, showcasing what Kinetic Dense is and what it is capable of.

### Tech Stack

- React 19 + TypeScript
- Vite 8 (build tooling)
- Tailwind CSS 4 (styling)
- Three.js + React Three Fiber (3D visualizations)
- Framer Motion (animations)
- GSAP (parallax effects)
- GitHub Pages (hosting)

### Running Locally

```bash
npm install
npm run dev
```

### Building

```bash
npm run build
```

The production build outputs to `dist/` and deploys automatically to GitHub Pages via Actions on push to `main`.
